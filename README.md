# Project_Web

A P2 web programming project on a subject of our choice !

## Theme

We decided to create a website around our common passion : video games. Well, not the usual video games funded by huge investors, carried by the brand's notoriety and made by professionals. No no, we're talking about video games realised by passionates and for passionates. Games created not by studios based in Silicon Valley but games made by only a few persons. Yes, we're talking about Indie Games !

## Having an issue ?

If the display seems off, or some links are not working, make sure you're running a Live Server, in order to make the JavaScript work.
If there are still issues, don't hesitate to send us a message or a mail.
